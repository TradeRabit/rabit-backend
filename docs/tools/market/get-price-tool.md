# Get Price Tool

This document describes the role of the `get_price`-style market lookup flow inside the backend tool layer.

## Purpose

Price lookup tools give the agent a fast path to current market information without forcing a full research flow.

## Typical Use Cases

- quick market checks
- validating the current price before analysis
- comparing current price with a planned setup
- feeding UI summaries or lightweight trading assistance
