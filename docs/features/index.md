# Features

This section is the product-style documentation surface for the backend.

Use it when you want to understand what the backend currently does without reading roadmap notes or low-level implementation logs.

## What Belongs Here

`docs/features` answers:

- what capability exists today
- what the backend does from a user or product point of view
- how major capabilities fit together at a high level

If you instead need provider-specific setup or storage details, use [Integrations](../integrations/index.md).

If you need streaming-source behavior, use [WebSocket and Market Data](../websocket/index.md).
