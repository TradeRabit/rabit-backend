# Real-Time Market Data

The backend aggregates market data from multiple sources for agent reasoning, charting support, and frontend display.

## Current Sources

- Drift
- Backpack
- Binance for OHLC-style historical data
- CoinGecko for metadata
- news sources for market narrative context

## Main Delivery Paths

- WebSocket market streams
- REST endpoints for selected asset and chart data
- agent tools for market analysis workflows
