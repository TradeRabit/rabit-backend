# Integrations

This section covers third-party integrations used by the backend.

## What Belongs Here

`docs/integrations` answers:

- which external provider or service is involved
- how credentials, auth, storage, or SDK setup work
- what environment variables or operational setup are needed

If you want the product-level behavior first, use [Features](../features/index.md).

If you want the stream-ingestion side first, use [WebSocket and Market Data](../websocket/index.md).
