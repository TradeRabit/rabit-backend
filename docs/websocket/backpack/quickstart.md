# Backpack WebSocket Quickstart

Use this guide if you want to understand the fastest path to Backpack-backed market streaming in the backend.

## What This Covers

- Backpack as a public market-data source
- WebSocket-based ticker and price usage
- where to look in the backend

## What This Does Not Cover

- Backpack API key storage
- authenticated account reads
- live Backpack order execution

For those, use:
